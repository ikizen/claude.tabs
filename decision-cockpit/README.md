# Decision Cockpit

Интерактивный дашборд решений по товарным запасам. Загружаете MD-отчёт (drag-and-drop) — сайт парсит его по фиксированному контракту и показывает как дашборд: KPI, статусы, прогноз, дефицит, закуп, задачи и т.д. Сайт read-only от файла — сам ничего не пересчитывает (кроме тривиальных отображаемых величин вроде % от суммы или дельты между соседними периодами).

Стек: Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui.

## Разработка

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000` и загрузите `sample-report.md` из корня репозитория, чтобы увидеть дашборд с демо-данными.

## Контракт MD-отчёта

Полное описание секций — `docs/report-contract-v3-addendum.md` (последнее дополнение) и `sample-report.md` (эталонный пример со всеми секциями).

## Сборка

```bash
npm run build
npm run start
```
